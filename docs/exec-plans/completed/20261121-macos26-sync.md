# 同步 macOS 26 维护线

## 目标和验收

从本地尺寸修复提交合并官方 legacy/thaw-2，保留延迟收起保护、浮动栏尺寸修复和独立产品身份。仅使用本地隔离分支。核验上游关系、Release 产品的部署目标、可隔离执行的测试及真实悬停的验证边界。

## 进展和决策

- 基线为干净的 compat/macos26-backports。候选源码版本为 compat26.2。
- 官方 2.x 最新稳定标签 2.1.0，预发布标签 2.2.0-beta.2。共同祖先 9b1796f 之后的维护线提交 51e8d6c 修复浮动栏的底色遮住图标。
- 两边均改动 IceBar.swift，Git 自动合并。更新日志保留两边的条目。复用已有 SwiftPM 依赖，在独立的 DerivedData 原生构建并检查产物。
- 根目录指南已保留上游贡献约定，并增加兼容线同步、隔离构建、四套无界面回归及真实菜单栏验收步骤。

## 验证结果和边界

- macOS 26.7.3，Xcode 27.2。通用 Release 构建及原生 arm64 Debug 的完整测试目标编译均通过。
- Release 主程序及两个 Thaw XPC 的 arm64、x86_64 Mach-O 最低系统均为 15.0，各自 Info.plist 一致。内嵌 Sparkle 与 Swift 兼容库的部署要求也低于 26。
- Release 自检覆盖 36 种延迟收起组合。4 项 Python 隔离检查通过。用候选自身的 Debug 动态库及原始测试目标文件链接独立 Swift Testing 入口，浮动栏着色、尺寸适配、收起策略和产品隔离共 33 个测试全部通过。完整宿主测试会启动 App，本次仅编译全套测试。
- SwiftLint 0.65.1 严格模式报告 11 项 `legacy_swiftui_aspect_ratio`。与合并前的本地基线按相对路径、行列、规则和原因比较，完全相同。SwiftLint 输入文件清单核对一致。
- 本次候选没有进入交互会话。无法从本次测试得出实际悬停、移出收起及点击表现。根目录指南记录了在独立会话中的复测方法。

## 结论

上游修复和已有定制可在保留原最低部署目标的条件下一起构建。两边对同一浮动栏文件的改动经逐项比对，分别处理着色与尺寸。着色测试覆盖透明度对图标背景的计算，尺寸测试覆盖取整与重复布局。桌面上的最终呈现仍需交互验收。
