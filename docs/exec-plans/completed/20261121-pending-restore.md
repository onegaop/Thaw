# macOS 26 自动恢复原邻居

在首开修复上验证隐藏区邻居恢复。现场报告显示源在屏上，隐藏邻居左侧落点在屏外。原路径可发送停放区移动，普通缓存刷新可反复重试。事件日志关闭，无法还原每次拖放。
在自动恢复的移动锁内临时展开，复查准确的邻居、显示器、分区及落点，恢复分隔符；为同一失败安排有限重试。人工布局、偏好、运行版及上游 PR 不在修改范围。
验收采用匿名合成几何、重试状态机、旧首开回归、独立宿主与 Release 构建。现场 WindowServer 拖放需另行验证。

## 决策与验证

- 保留正常停放区传输和手动编辑。仅自动还原普通邻居时，在移动锁内暂时展开原生分隔符。移动前、事件发送时以及恢复分隔符后分别验证目标；目标换区时退回请求的分区。写回待办取决于保存的一侧、相邻关系以及仍有效的原请求。
- 相同目标失败后分别等待 30、60、90 秒。用尽后仍保留待办，每五分钟仅重新检查几何。位置仍不可达时保留一份本地失败诊断。清除待办会同时清除重试状态。
- 在 macOS 26.7.3、Xcode 27.2 上，完整 Debug 测试目标构建成功。旧规划器对照产生 11 处失败断言；候选的 13 个独立套件共运行 128 项并通过。全库严格 SwiftLint 的 11 项与基线逐项相同。
- 原首开渲染、收起和身份隔离回归继续通过。检查使用独立测试宿主、合成窗口及时间数据。未对正在运行的应用发送拖放；这类测试无法确认 WindowServer 会接受实际手势。现场验收需在候选自然触发时检查隐藏区原邻居的正确一侧及重复诊断。
